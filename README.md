## Project Overview
This repository contains six Machine Learning prediction projects developed using Python and Scikit-learn.

## Projects

### 1. Student Success Prediction
Predicts student performance based on study hours, attendance, previous marks and income level.

### 2. Loan Approval Prediction
Predicts whether a loan application will be approved or rejected based on applicant details.

### 3. Disease Prediction
Predicts possible diseases based on symptoms such as fever, cough, headache and fatigue.

### 4. House Price Prediction
Predicts house prices using relevant property features.

### 5. Sales Prediction
Predicts sales using historical sales-related data.

### 6. Customer Churn Prediction
Predicts whether a customer is likely to leave a service.

## Technologies Used

- Pandas

- Scikit-learn
- Random Forest Classifier
- Machine Learning

The projects use machine learning model evaluation techniques such as:
